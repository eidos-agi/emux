# What Emux is

Emux is a human control room for live trees of AIs. Each node is an active AI session. A directed edge means one AI manages, delegates to, or steers another. The human stays above the tree: observing its state, selecting any node, redirecting work, interrupting a bad path, and approving consequential gates.

Flow is the primary conceptual view because it shows the tree itself. Managers and orchestrators sit above the agents they direct. Grid, Groups, and Activity are supporting views of the same live system: what exists, how it is organized, and what has changed.

Channels are persistent work contexts. Like changing a television channel, an operator can move from engineering to finance or another body of work while the other AI trees continue running. Emux keeps their operational state visible when the human returns.

Hancock owns consequential human approvals. Emux detects a gate, identifies the exact target, waits for a bounded decision, and executes only the authorized action when the live gate still matches.

Emux is deliberately memory-light. It proves how humans can manage trees of AIs. Fleet is the downstream system that learns to manage those trees, and Eidos Omni is Fleet's durable memory authority. Emux builds Fleet; Fleet does not redefine Emux before the operating model is proven.
