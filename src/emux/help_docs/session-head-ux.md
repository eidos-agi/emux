# Session head target UX

When you open a live session, the target layout is:

1. **Left** — full head (terminal), gist, key chips, composer (with auth mode + send).
2. **Right** — tabbed drawer: **Tasks** (Linear keys found in this chat), **Chat** (as many side chats as you want), **Context** (seat metadata).

Full design note (mockup, principles, gap map):

- Docs repo path: `docs/target-ux-session-head.md`
- Mockup image: `docs/images/target-ux-sidechats-linear.png`

**What works today:** Linear linkify + 💬 pursue, Tasks drawer, multi side-chat stack.  
**What the mockup still asks for:** dock Chat into the drawer tabs, Context tab, active issue in the header title, Queue vs Send Now, per-session authorization card.
