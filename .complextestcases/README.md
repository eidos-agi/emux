# .complextestcases

The case authority for this repo.

`cases.jsonl` — every case ever authored (append-only; amendments and
retirements are events, never edits).
`runs.jsonl` — every run ever executed. THIS IS THE PROOF: it is the only
place a case's falsifiability can be established, because it is the only
record of a case having been seen RED.

The rule: **a case must have been observed RED at least once.** A test
that has never failed has never been tested.
